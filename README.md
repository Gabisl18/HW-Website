# Surf Culture

A multi-page static website about surfing, built for a class assignment using
only HTML, CSS, and JavaScript — no frameworks or build tools.

**Live site:** https://gabisl18.github.io/HW-Website/index.html

## Pages

- **Home** (`index.html`) — intro to surfing, site overview, and a surf-quote generator
- **History** (`history.html`) — a timeline from ancient Polynesia to the modern shortboard era
- **Gear Guide** (`gear.html`) — a board-type comparison table and an interactive wetsuit thickness calculator
- **Contact** (`contact.html`) — a contact form with client-side validation

## Structure

```
index.html
history.html
gear.html
contact.html
css/style.css
js/script.js
```

## Running locally

Since this is a static site, just open `index.html` in a browser, or serve the
folder with any static file server, e.g.:

```
npx serve .
```

## Deployment

Hosted with GitHub Pages, deployed from the `main` branch.
